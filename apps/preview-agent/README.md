# Preview agent

Credential-free, single-submission client for separately pinned offline and live
model broker profiles. Live mode still has no provider credentials or direct
network access; only the server performs the fixed provider request.
Its packaged typed input, immutable artifact identity, sandbox and acceptance
workflow are documented in [the artifact guide](../../packaging/agent/README.md).
This program returns a proposal; local robot authorization and the kernel gate
remain mandatory.
